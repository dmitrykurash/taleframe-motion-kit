Before building, the agent adds a style sheet (palette, type, motion character, transition vocabulary, pacing, finish) and a shot list that alternates type and UI shots. For each shot, record its elapsed time, type (TYPE, UI, PRODUCT, BRAND), message, visible content, action, camera target, background, and how it arrives (cut or transition). Include a reading hold after key copy or state changes. Note staged data and deliberate UI simplifications so the next editor can distinguish them from the product itself.
